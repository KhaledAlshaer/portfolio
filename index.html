// Executive Summary

Reconstructing the Conti Ransomware Killchain

This investigation details the end-to-end tactical timeline of a simulated ransomware attack executed by the Conti threat group. By executing defensive event correlation on compromised IIS web servers and Windows endpoints within an enterprise environment using Splunk SIEM, the adversary’s actions were isolated, traced, and cataloged into actionable Indicators of Compromise (IOCs).

[PHASE 01: INITIAL ACCESS & WEB SHELL PERSISTENCE]

Scanned corporate internet-facing services using precise log filtering metrics. Analyzing web activity isolated a suspicious anomalous access pattern on an exchange landing directory.

sourcetype="iis" cs_method=POST
Target Endpoint: /owa/auth/i3gfPctK1c2x.aspx
[PHASE 02: MASQUERADING & ACCOUNT PROVISIONING]

The threat actor utilized process masquerading to execute administrative commands while evading default security analytics engines.

# Execution Path:
c:\Users\Administrator\Documents\cmd.exe
# Backdoor User Added:
net user /add securityninja hardToHack123$
[PHASE 03: PROCESS MIGRATION & EVASION]

Audited endpoint creation telemetry using internal event filters to capture systemic evasion maneuvers and execution handoffs.

EventCode=8 (Source Process Migration)
From: powershell.exe
To: \wbem\unsecapp.exe (WMI Subsystem)
[PHASE 04: CREDENTIAL DUMPING]

Once migrated to the system subsystem framework, the execution binary was redirected to extract security hashes straight from system volatile storage.

Target Memory Space: lsass.exe
Objective: Local Security Authority Subsystem hash retrieval

Dissecting Malicious Email Architecture & Payloads

This section documents the technical analysis of two targeted phishing campaigns. By checking raw email transportation data headers, converting obfuscated payload delivery metrics safely within sandboxed execution environments, and tracking downstream attacker command frameworks, active indicators of compromise were mapped.

[CAMPAIGN 01: THE GREENHOLT PHISH]

Analyzed raw text transportation blocks to trace malicious delivery routing records. Verified authentication compliance rules and isolated external hosting locations using reputation checks.

Originating ASN: Hostwinds LLC (Kansas, USA)

Payload Signature: Trojan with active file-spreading capabilities (SHA-256 Verified via VirusTotal)
